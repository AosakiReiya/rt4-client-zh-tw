2009scape 正體中文單機版
========================

免安裝、離線單機遊玩的 2009scape（2009 年風貌的 Runescape 開源復刻），
全介面與遊戲文字已漢化為正體中文。

系統需求
--------
- Windows x64 或 Linux x64
- 記憶體 4 GB 以上（伺服器會佔用約 2 GB）
- 已內含 Java 執行環境，無需另行安裝 Java

開始遊玩
--------
Windows：雙擊 start-game.bat
Linux：  終端機執行 ./start-game.sh（首次請先 chmod +x start-game.sh）

流程說明：
1. 腳本會先啟動離線伺服器（Windows 會另開一個主控台視窗，遊戲期間請勿關閉）。
2. 約 25 秒後自動開啟遊戲客戶端。
3. 在登入畫面直接建立免費帳號（帳號存在本機 game/data/players/），即可開始遊戲。

啟動後請先稍等片刻：第一次進入遊戲時，客戶端會從本機伺服器载入遊戲資料，
速度受限於本機磁碟，需 1～3 分鐘不等。若客戶端顯示連線失敗，
代表伺服器還沒準備好，等幾秒再按 Retry 或重啟腳本即可。

存档位置
--------
game/data/players/      角色資料
game/data/cache/        遊戲資產（僅伺服器使用）

已知限制
--------
- OpenGL 渲染模式下中文字以佔位寬度顯示（請使用軟體渲染，預設即軟體渲染）。
- 聊天輸入框不支援中文輸入（顯示皆為中文）。
- 部分複雜動態拼接句子可能仍顯示英文原文。
